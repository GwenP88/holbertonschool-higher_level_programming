## Introduction

This repository contains all my Higher Level Programming projects completed as part of my software engineering training.  
It focuses on learning Python fundamentals, object-oriented programming, data structures, testing methodologies, and advanced software design concepts.

Throughout these projects, I progressively build strong foundations in writing clean, readable, and maintainable code while following Python best practices and style guidelines. Each project reinforces problem-solving skills, logical thinking, and structured programming.

The goal of this repository is to demonstrate consistent progress from basic syntax to advanced object-oriented design and data manipulation techniques.

---

## Projects Overview

### Python - Hello, World
This project introduces the basics of Python programming. It focuses on using the Python interpreter, printing text and variables, manipulating strings, and understanding indexing and slicing. It also introduces the official Python coding style and how to check code quality using `pycodestyle`.

### Python - if/else, loops, functions
This project explores control flow in Python. It covers indentation rules, conditional statements, loops (`for`, `while`), variable assignment, comments, arithmetic operations, and function definition. It also introduces scope, return behavior, and basic debugging through tracebacks.

### Python - import & modules
This project focuses on modular programming in Python. It teaches how to import functions from other files, create modules, use built-in functions like `dir()`, and prevent code execution when a file is imported. It also introduces command line arguments in Python scripts.

### Python - Data Structures: Lists, Tuples
This project introduces fundamental data structures such as lists and tuples. It covers list methods, list comprehensions, stack and queue usage, tuple packing and unpacking, sequences, and the differences between mutable and immutable data types.

### Python - More Data Structures: Set, Dictionary
This project expands knowledge of Python data structures with sets and dictionaries. It explains when to use each structure, how to iterate over them, and how to use common methods. It also introduces lambda functions and functional tools such as `map`, `filter`, and `reduce`.

### Python - Exceptions
This project focuses on error handling in Python. It explains the difference between errors and exceptions, how to catch and raise exceptions, and when to implement cleanup actions. The goal is to write more robust and fault-tolerant programs.

### Python - Test-driven development
This project introduces the principles of Test-Driven Development (TDD). It emphasizes writing documentation and tests before implementation, using `doctest`, identifying edge cases, and understanding why testing is essential for reliable software development.

### Python - Classes and Objects
This project introduces Object-Oriented Programming (OOP) in Python. It covers classes, objects, attributes, methods, encapsulation, properties, and the `__init__` method. It also explains data abstraction, information hiding, and how Python handles attribute lookup.

### Python - More Classes and Objects
This project deepens OOP concepts. It explores class attributes, instance attributes, class methods, static methods, and special methods like `__str__` and `__repr__`. It also reinforces encapsulation and the internal structure of classes through `__dict__`.

### Python - Inheritance
This project focuses on inheritance in Python. It explains parent and child classes, method overriding, multiple inheritance, and the use of built-in functions such as `isinstance`, `issubclass`, `type`, and `super`. It highlights how inheritance promotes code reuse and structure.

### Python - Abstract Classes and Interfaces
This project introduces advanced OOP concepts such as abstract base classes, interfaces, duck typing, mixins, and method overriding. It focuses on designing flexible and maintainable architectures using well-defined contracts between classes.

### Python - Input/Output
This project covers file handling and data persistence. It explains how to read and write files, use the `with` statement, handle file cursors, and work with JSON for serialization and deserialization. It also introduces command line parameters through the `sys` module.

### Python - Serialization
This project explores marshaling and serialization concepts. It explains how to convert objects into formats suitable for storage or transmission (JSON, XML, binary), how to preserve object state, and how serialization is used in distributed systems, databases, and network communication.
